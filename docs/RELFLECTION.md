# Reflections


## GOTO

using GOTO statement in PL/SQL

syntax:

```sql
<<label_name>>

GOTO label_name;
```

> GOTO changes the normal flow of a PL/SQL
> program by jumping to a label.

## Functions

I learned that a PL/SQL function receives parameters,
performs an operation and returns a value.

> Functions Differ from procedures because they return a value whereas Procedures Don't return a value.
